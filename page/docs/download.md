# 下载

目前提供 Windows 便携版，无需安装。

<DownloadCard />

::: tip 发布页里下载哪个文件？
进入最新版本，下载名称中带 `portable` 的发布包。`Source code` 是源码归档，不是可直接运行的程序。
:::

## 系统要求

- Windows 10 或更高版本
- 建议 4GB 及以上内存
- 约 100MB 可用磁盘空间

## 安装提示

1. 下载发布包并完整解压，不要直接在压缩包内运行
2. 将程序放在有写入权限的目录
3. 运行 `pure_music.exe`，按欢迎页提示添加音乐文件夹

::: info SmartScreen
首次运行时 Windows 可能弹出 SmartScreen 提示，点击「更多信息」→「仍要运行」即可。
:::

配置、曲库与缓存默认写在程序旁的 `data/`。备份或迁移时，请保留整个程序目录；更多见 [安装指南](/guide/install) 与 [常见问题](/guide/faq)。
