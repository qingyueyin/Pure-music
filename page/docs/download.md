## 版本说明

| 版本类型 | 说明 |
|---------|------|
| 稳定版 | 经过充分测试，推荐日常使用 |
| 预览版 | 包含最新功能，可能存在不稳定因素 |

## 系统要求

- Windows 10 或更高版本
- 建议 4GB 及以上内存
- 约 100MB 可用磁盘空间

## 安装提示

::: info SmartScreen
首次运行时 Windows 可能弹出 SmartScreen 提示，点击「更多信息」→「仍要运行」即可。
:::

默认便携模式：配置与曲库写在程序旁 `data/`。更多见 [安装指南](/guide/install) 与 [常见问题](/guide/faq)。
