# 播放与音频

## 播放控制

| 能力 | 说明 |
|------|------|
| 播放模式 | 顺序 / 列表循环 / 单曲循环 |
| 随机 | 可开启，会话中会记住状态 |
| 会话恢复 | 记住上次曲目、队列与 shuffle |
| 淡入淡出 | 共享模式下切歌过渡 |
| SMTC | 系统媒体控件：播放 / 暂停 / 上下曲 |

## 音调与速度

- 支持半音音调调节、播放速度调节
- 可选 KeepPitch（变速保调）
- **主要在共享输出模式下生效**；切换到 WASAPI 独占时可能回退

## 10 段均衡器

频点：80 / 100 / 125 / 250 / 500 / 1k / 2k / 4k / 8k / 16k Hz

- 支持预放大、自动增益、预设
- **EQ 非零时与 WASAPI 独占互斥**：想开独占，先把 EQ 归零

## 输出模式

| 模式 | 适合 | 注意 |
|------|------|------|
| 共享（默认） | 日常使用 | 支持 crossfade、音调 / 速度、EQ |
| WASAPI 独占 | 更低延迟 / 更直接输出 | 可能占用设备；与 EQ 冲突；失败时会提示 BUSY |

独占失败常见原因：其它程序占用声卡。关闭占用程序后重试。

## ReplayGain 与音量

- 若标签含 track gain，可按增益叠到输出
- 另有 DSP 音量；快捷键 `Ctrl + ↑/↓` 调节

## 播放页布局

- 竖屏 / 横屏自动适配
- `F1` 沉浸模式
- 背景：封面模糊、网格渐变、音频律动等（在设置 / 播放页相关选项中切换）
