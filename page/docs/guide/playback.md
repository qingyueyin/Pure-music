# 播放与音频

## 播放控制

| 能力 | 说明 |
|------|------|
| 播放模式 | 顺序 / 列表循环 / 单曲循环 |
| 随机 | 可开；关闭或重启后会尽量记住你的选择 |
| 会话恢复 | 下次打开尽量回到上次的歌和播放列表 |
| 淡入淡出 | 普通（共享）模式下切歌会有短暂过渡；独占模式是直接切 |
| 系统媒体控件 | 任务栏 / 键盘媒体键：播放、暂停、上下曲、拖进度 |

## 音调与速度

在播放页打开音调面板：

- 可调半音（大约高 12 到低 12）和播放速度
- **保持音调**：变速时尽量不跑调；打开后，半音变调通常不能同时用
- 这两项主要在**共享输出**下有效；开了 WASAPI 独占后可能失效

## 均衡器

播放页打开 EQ：

- 10 个频段（低音到高音），每段大约 ±15 dB
- **前级增益**：整体再抬高或压低一点（大约 −24 ~ +24 dB）
- 可保存 / 删除 / 套用预设
- 支持导入常见 AutoEq 曲线（文本或整个文件夹）
- **EQ 没有全部归零时，不能开独占**；想独占请先把各段和前级都拉回中间

## 输出模式

| 模式 | 适合 | 注意 |
|------|------|------|
| 共享（默认） | 日常听歌 | 可用淡入淡出、音调、速度、EQ；蓝牙设备请用这个 |
| WASAPI 独占 | 更想「直接」出声 | 可能占住声卡；与 EQ 冲突；**蓝牙多数不支持**；失败会提示并退回共享 |

独占打不开时：先关占声卡的程序，EQ 全部归零；若是蓝牙耳机/音箱，请改回共享模式（多数蓝牙开不了独占）。

## 音量与 ReplayGain

播放页点音量，会看到两档：

| 项 | 怎么用 |
|----|--------|
| 应用音量 | 只调本软件大小；快捷键 `Ctrl + ↑/↓` 也是调这一档 |
| 系统音量 | 调 Windows 总音量 |

两档互不影响。

**ReplayGain**（设置 → 高级）：如果歌曲标签里带有音量信息，可自动把偏大/偏小的歌拉齐一点。标签里没有则无效果。

## 播放页怎么看

- 窗口变窄 / 变宽会自动换成竖屏或横屏布局
- `F1` 进出沉浸（少干扰看歌词）
- 可在「只看封面主区 / 带歌词 / 带当前播放列表」之间切换
- 封面会跟着主题色一起变；进度条是否做成波浪，在「设置 → 外观」里按竖屏、横屏、沉浸分别勾选

背景是封面取色后的流动渐变，随当前歌曲变化。
