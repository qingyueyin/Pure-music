# 播放与音频

## 播放控制

| 能力 | 说明 |
|------|------|
| 播放模式 | 顺序 / 列表循环 / 单曲循环 |
| 随机 | 可开；关闭或重启后会尽量记住你的选择 |
| 专辑播放 | 专辑详情页可以一键顺序播放或随机播放当前列表 |
| 会话恢复 | 下次打开尽量回到上次的歌和播放列表 |
| 切歌衔接 | 可选无缝、淡入淡出、交叉淡化或智能切歌；淡入和淡出时长可以分别调节 |
| 系统媒体控件 | 任务栏 / 键盘媒体键：播放、暂停、上下曲、拖进度 |

主界面底部迷你播放条的进度条支持长按和拖动，可以不进入完整播放页直接跳到指定位置。

## 切歌过渡

设置 → 播放中可选四种过渡模式：

| 模式 | 效果 |
|------|------|
| 无缝衔接 | 曲尾零间隙，上一首结束瞬间切换下一首（gapless） |
| 淡入淡出 | 旧歌淡出后新歌淡入，淡出和淡入时长可分别调节（0–10 秒） |
| 交叉淡化 | 两首歌重叠混音，旧歌淡出的同时新歌淡入，时长可调 |
| 智能衔接 | 根据歌曲特征自动选择最合适的衔接方式 |

选淡入淡出或交叉淡化时，下方会出现淡出/淡出时长滑块。智能衔接会结合歌曲尾部静音长度、节奏等因素决定用哪种模式。

## 音调与速度

在播放页打开音调面板：

- 可调半音（大约高 12 到低 12）和播放速度
- **保持音调**：变速时尽量不跑调；打开后，半音变调通常不能同时用
- 这两项主要在**共享输出**下有效；开了 WASAPI 独占后可能失效

## 均衡器

播放页打开 EQ：

- 10 个 ISO 频段：31 / 62 / 125 / 250 / 500 / 1k / 2k / 4k / 8k / 16k Hz，每段大约 ±15 dB
- 所有频段使用同一套峰值滤波语义；旧版本的 80 / 100 Hz 配置会按频率迁移
- **前级增益**：整体再抬高或压低一点（大约 −24 ~ +24 dB）
- **自动防削波**：按整条 EQ 响应和前级增益估算峰值，只自动降低整体增益，并显示当前衰减量
- 可保存 / 删除 / 套用预设
- 内置预设只调整 EQ、前级和自动防削波；自己保存的预设还会保存 EQ 开关和 DSP 状态
- 支持导入常见 AutoEq 曲线（文本或整个文件夹）
- 播放页还提供高通、低通、驱动、混响、压缩和峰值保护；处理顺序是 **EQ → 滤波 → 染色 → 压缩 → 输出 → 峰值保护**

## 输出模式

| 模式 | 适合 | 注意 |
|------|------|------|
| 共享（默认） | 日常听歌 | 可用淡入淡出、音调、速度、EQ；蓝牙设备请用这个 |
| WASAPI 独占 | 更想「直接」出声 | 可能占住声卡；切换时会自动关闭非中性 EQ、DSP、速度或音调；**蓝牙多数不支持**；失败会提示并退回共享 |

切到独占时，受影响的功能会自动关闭，EQ 曲线和 DSP 参数仍会保留；切换结果和被关闭的功能会通过提示条显示。若设备初始化失败，会保留原有的失败和回退提示。

## 音量与 ReplayGain

播放页点音量，会看到两档：

| 项 | 怎么用 |
|----|--------|
| 应用音量 | 只调本软件大小；默认快捷键 `Ctrl + ↑/↓` 也是调这一档 |
| 系统音量 | 调 Windows 总音量 |

两档互不影响。

ReplayGain（设置 → 播放）：如果歌曲标签里带有音量信息，可自动把偏大/偏小的歌拉齐一点。标签里没有则无效果。

## 睡眠定时

播放页点击「睡眠定时」可设置倒计时，到时间后自动暂停播放。开启「延长」模式时，定时结束后会等当前歌曲播完再暂停，避免歌曲中途被打断。

## 播放页怎么看

- 窗口变窄 / 变宽会自动换成竖屏或横屏布局
- `F1` 进出沉浸（少干扰看歌词）
- `F11` 最大化或还原窗口
- 可在「只看封面主区 / 带歌词 / 带当前播放列表」之间切换
- 横屏播放页底部有收起按钮；歌词来源按钮会标出当前使用的是内嵌、外置还是在线歌词
- 「设置 → 播放 → 任务栏」可分别开关缩略图播放按钮和 Alt+Tab 封面预览，并调节封面预览大小
- 封面会跟着主题色一起变；进度条是否做成波浪，在「设置 → 外观」里按竖屏、横屏、沉浸分别勾选

背景是封面取色后的流动渐变，随当前歌曲变化；智能切歌会结合歌曲特征选择更合适的衔接方式。
