# 播放与音频

声音在播放页调，切歌和音量拉齐在设置里。

## 播放模式

**顺序** — 按列表播完再从头

**单曲循环** — 重复当前曲

**随机** — 打乱顺序

## 播放页

**10 段 EQ** — 播放页打开均衡器。频段 31 / 62 / 125 / 250 / 500 Hz / 1K / 2K / 4K / 8K / 16K，可预设或自定义。

**WASAPI 独占** — 绕过混音器直出硬件。独占时其他应用没声。
**输出设备** — 设置 → 播放 → 输出设备 →「选择」，默认跟随系统默认设备，也可以指定具体设备。

**音调 / 速度** — 半音变调，0.5x–2.0x 变速，可保持音调。

## 切歌过渡

设置 → 播放 → 播放行为。无缝 / 淡入淡出 / 交叉淡化，淡入、淡出时长可分开调。

同一组里还有 ReplayGain（按曲目或专辑拉齐音量）和跳过片头空白。
