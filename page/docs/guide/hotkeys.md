# 快捷键

应用内快捷键只在窗口前台生效；全局热键最小化或切到其它窗口也能用。键位在「设置 → 播放」里改。

## 默认应用内快捷键

| 按键 | 作用 |
|------|------|
| `Space` | 播放 / 暂停 |
| `Esc` | 先关弹窗；没有弹窗则退出沉浸；再按可返回 |
| `Ctrl + ←` | 上一首 |
| `Ctrl + →` | 下一首 |
| `Ctrl + ↑` | 本软件音量加大（不是系统总音量） |
| `Ctrl + ↓` | 本软件音量减小 |
| `F1` | 进出沉浸模式 |
| `F11` | 全屏 / 还原窗口 |
| 鼠标侧键（后退） | 返回；沉浸里会先退出沉浸 |

## 全局热键

默认关闭。打开后可以为播放 / 暂停、上一首、下一首单独录一组组合键。全局热键需要带 `Ctrl` / `Alt` / `Shift`，避免抢游戏里的单键。

管理员权限运行的游戏仍可能拦截热键，这点和系统其它软件一样，不需要把本软件改成管理员启动。

## 没反应时先看这几条

1. 是不是正在搜索框或其它输入框里打字？（这时应用内播放快捷键会暂时关掉）
2. 有没有对话框挡着？（先按 `Esc`）
3. 全局热键有没有打开？组合键有没有被其它软件占用？
4. 耳机 / 键盘上的「媒体键」走系统媒体控件，和上表是两套，一般可以一起用  

系统总音量：点播放页音量，用下面那一条。更多鼠标操作见 [交互与手势](/guide/interactions)。
