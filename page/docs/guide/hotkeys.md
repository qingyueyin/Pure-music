# 快捷键

下面这些是**固定**的，设置里不能改键位。

| 按键 | 作用 |
|------|------|
| `Space` | 播放 / 暂停 |
| `Esc` | 先关弹窗；没有弹窗则退出沉浸；再按可返回 |
| `Ctrl + ←` | 上一首 |
| `Ctrl + →` | 下一首 |
| `Ctrl + ↑` | 本软件音量加大（不是系统总音量） |
| `Ctrl + ↓` | 本软件音量减小 |
| `F1` | 进出沉浸模式 |
| 鼠标侧键（后退） | 返回；沉浸里会先退出沉浸 |

## 没反应时先看这几条

1. 是不是正在搜索框或其它输入框里打字？（这时播放快捷键会暂时关掉）  
2. 有没有对话框挡着？（先按 `Esc`）  
3. 别的软件有没有占用同样的全局热键？  
4. 耳机 / 键盘上的「媒体键」走系统媒体控件，和上表是两套，一般可以一起用  

系统总音量：点播放页音量，用下面那一条。更多鼠标操作见 [交互与手势](/guide/interactions)。
