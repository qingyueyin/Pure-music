# 歌词

## 本地歌词怎么放

把歌词文件和歌曲放在**同一文件夹**，文件名尽量一致，例如：

`歌名.flac` → `歌名.lrc` / `歌名.ttml` / `歌名.yrc`

同目录有多份时，大致优先顺序：

`.yrc` > `.qrc` > `.krc` > `.ttml` > `.lrc`

还会尝试：近似文件名、写在音频里的内嵌歌词、常见中文/日文编码。部分加密格式会自动处理。

## 哪些是逐字、哪些是逐行

| 格式 | 常见效果 |
|------|----------|
| 普通 LRC | 多半一行一行亮 |
| 增强 LRC、YRC / QRC / KRC、不少 TTML | 可以一个字一个字跟 |

**能不能逐字，取决于歌词文件本身**，没有「强制变成逐字」的开关。

## 在线歌词

「设置 → 歌词」里选**首选来源**：

| 模式 | 行为 |
|------|------|
| 本地 | 只读外挂和内嵌，**不会**自动上网搜 |
| 在线 | 只按你选的源搜（QQ / 网易 / 酷狗 / AMLL），**不会**自动改回本地文件 |

对不上时：

1. 换一个在线源  
2. 检查歌曲的歌名、艺人标签对不对  
3. 播放页「更多 → 歌词来源」里手动搜索，或指定某个本地文件  

不是每首歌、每个源都有翻译或注音；源里没有时，软件不会自己编。

## 原文、翻译、注音

有数据时可以一起显示。在「设置 → 歌词」调：

- **注音位置**：在原文上面 / 下面 / 在翻译下面  
- **简繁转换**：不转 / 繁→简 / 简→繁  

两件不同的事：

| | 在哪 | 管什么 |
|--|------|--------|
| 注音位置 | 设置 → 歌词 | 注音排在原文上 / 下 / 翻译下 |
| 显示开关 | 播放页展开歌词控件 | 要不要显示翻译、注音（**没有数据时开关是灰的**） |

时间轴乱、翻译对不齐时，优先怀疑**外挂 / 内嵌歌词文件质量**；可改用在线搜一条，或换更好的本地文件。详见 [FAQ](/guide/faq#原文--翻译--注音对得不准对不齐)。

## 跟唱时你会感觉到的细节

这些不用设置，软件会自动做：

- 下一句会稍稍提前一点接上，减少「慢半拍」的感觉  
- 一句快结束时，如果高亮有点拖，会加快收尾，避免卡在最后一个字  
- 开头结尾常见的「词：xxx / 曲：xxx」会收掉，不挡跟唱  
- **开头前奏**（第一句之前的长空白）和 **中间间奏**（两句之间的长空白）是分开的；空档大约 **5 秒以上** 才容易出动画，逐字/逐行算法略有差别，详见 [FAQ](/guide/faq#开头没有前奏动画中间没有间奏动画)  
- 间奏**颜色**在「设置 → 外观 → 主题色间奏动画」，与「会不会出现」无关

桌面歌词的跟唱节奏和播放页一致。

## 怎么调显示和动效

### 播放页（展开歌词控件）

- 字号、粗细、左中右对齐  
- 非当前行是否模糊  
- **翻译、注音**显示开关（有数据才能开；原文一般始终显示）  

字号、粗细的鼠标用法见 [交互与手势](/guide/interactions)。

多声部（例如对唱分左右）时，对齐按钮可能隐藏，左右排布由歌词文件决定。

### 设置 → 歌词

| 你想… | 去哪调 |
|--------|--------|
| 字变大时带一点光、拖长音更明显 | **辉光缩放**（默认关；只有**逐字**且字够长才明显，见 [FAQ](/guide/faq#开了辉光缩放为什么几乎看不出)） |
| 换行时整句动得更弹或更顺 | **歌词行动效**：平滑 / 弹簧 |
| 正在唱的字微微抬起 | **逐字上抬**（垂直或余弦；可调幅度和持续时间） |

### 其它小体验

- 歌词列表上下边缘会略微变淡  
- **用手滑了一下歌词**后，大约 2 秒内不会强行滚回当前句，方便你自己翻  
- 窗口顶部那一行小歌词的切换动画，在「设置 → 外观」  
- 带伴唱/和声的 TTML，副声部会淡一些，不抢主歌词  

独立窗口见 [桌面歌词](/guide/desktop-lyric)。设置总表见 [外观与设置](/guide/settings)。

## 没有歌词时

1. 文件是否和歌曲同目录、同名  
2. 扩展名是否支持  
3. 用记事本另存为 UTF-8 再试  
4. 需要上网搜：首选来源改成「在线」  
5. 仍不对：播放页「更多 → 歌词来源」手动搜或指定文件
