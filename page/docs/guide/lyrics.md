# 歌词

## 本地外挂优先级

同目录下，按扩展名优先级加载：

`.yrc` > `.qrc` > `.krc` > `.ttml` > `.lrc`

另外还会尝试：

- 同名 / 近似文件名匹配
- 音频内嵌歌词
- 多编码读取（UTF-8 / GBK / Shift-JIS 等）
- QRC / KRC 解密路径

::: tip 命名建议
尽量让歌词与音频同名：`song.flac` → `song.lrc` / `song.ttml` / `song.yrc`。
:::

## 格式能力

| 格式 | 说明 | 同步 |
|------|------|------|
| LRC | 常见逐行歌词 | 行 |
| 增强 LRC | 带更细时间戳 | 字 / 行 |
| TTML | 结构化时间文本 | 字 / 行 / 分组 |
| YRC / QRC / KRC | 常见逐字源格式 | 字 / 行 |

是否呈现逐字，**主要由歌词文件本身决定**，不是靠某个开关“强行转换”。

## 在线歌词

歌词来源分为本地与在线两种模式。在线模式默认使用 QQ，也可切换网易、酷狗或 AMLL。

- 本地模式只读取外挂与内嵌歌词，不自动搜索网络
- 在线模式只搜索所选在线源，不自动回退到本地歌词
- 匹配不准时：换源、检查歌名 / 艺人标签、或手动指定更合适的本地文件

## 原文 / 翻译 / 罗马音

支持多语言分组显示：

- 原文
- 翻译
- 罗马音（注音）

注音位置可调：原文上 / 原文下 / 翻译下。  
另支持简繁转换：不转换 / 繁→简 / 简→繁。

## 显示与动效

播放页歌词可配置：

- 字号、行距、对齐
- 逐字卡拉 OK 渐变
- 行模糊、缩放、间奏动画
- 顶部栏歌词切换动画

桌面端独立窗口见 [桌面歌词](/guide/desktop-lyric)。

## 找不到歌词时

1. 确认文件与音频同目录、同名
2. 确认扩展名在支持列表内
3. 检查编码是否异常（可用编辑器另存为 UTF-8）
4. 需要联网搜索时，将首选歌词来源切换为「在线」并选择对应来源
