# 音乐库

## 添加与排除

- 首次启动：欢迎页选择音乐根目录
- 之后：在「文件夹」中添加更多目录，或设置排除文件夹
- 扫描会递归子目录，索引写入本地 SQLite（`library.sqlite`）

## 浏览方式

| 视图 | 说明 |
|------|------|
| 音乐 | 全部曲目 |
| 艺术家 | 按艺人聚合，支持自定义分隔符（如 `/`、`、`） |
| 专辑 | 按专辑聚合 |
| 文件夹 | 按实际目录 |
| 歌单 | 用户自建列表 |
| 统计 | 基于播放次数的常用曲目 |

支持列表 / 表格视图与排序。

## 搜索

全局搜索可覆盖歌曲、艺术家、专辑。适合大库快速定位。

## 支持的音频格式

常见可扫描格式包括：

`mp3` · `flac` · `wav` · `m4a` · `aac` · `ogg` · `opus` · `ape` · `wv` · `aiff` · `wma` · `webm` · `dsf` 等

实际播放依赖内置音频引擎与格式插件。若某格式能扫描但无法播放，优先检查文件是否损坏、是否为不支持的编码变体。

## 封面与标签

- 标签与封面由后端读取
- 封面会缓存，减少重复解码
- 大库首次建索引会更吃磁盘与时间，属正常现象

## 数据位置

便携模式下，曲库与配置在程序旁 `data/`。备份或迁移时，拷贝整个程序目录（含 `data/`）即可。
