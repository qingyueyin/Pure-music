# 音乐库

直读本地文件，不复制、不上传。

## 浏览

**音乐** — 全部歌曲

**艺术家 / 专辑** — 按标签分组

**文件夹** — 按目录结构

**远程音乐** — NAS 或服务器上的曲库，见「远程音乐」

**歌单** — 自建列表

**统计** — 收听记录

## 曲库

**添加文件夹** — 「文件夹」→「文件夹管理」→「添加」。选上层目录，子文件夹会递归扫描。

**刷新** — 本地文件有改动后，到「文件夹」点「刷新」。只重启软件不会扫新文件。

**移除文件夹** — 「文件夹管理」→「移除」。歌曲从曲库消失，磁盘文件还在。

## 标签

点进歌曲详情 →「编辑标签」。可改标题、艺术家、专辑、专辑艺术家、年份、音轨号、封面。

改完后刷新曲库，列表才会跟上。
