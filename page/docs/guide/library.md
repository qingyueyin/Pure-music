# 音乐库

## 添加与排除

- 首次启动：欢迎页选择音乐根目录
- 之后：进入「文件夹」→「文件夹管理」添加或移除目录
- 扫描会递归子目录，索引写入本地 SQLite（`library.sqlite`）
- 从曲库移除目录不会删除本地音乐文件

## 更新曲库

- 已添加目录中有新增、修改或删除的文件时，在「文件夹」页点击「刷新」
- **只重启软件不会自动扫盘**；不点刷新，新拷进去的歌不会出现
- 修改扫描目录后，确认设置会重新构建曲库
- 修改音乐标签后，需要刷新曲库才能在列表中看到新内容

## 浏览方式

| 视图 | 说明 |
|------|------|
| 音乐 | 全部曲目 |
| 艺术家 | 按艺人聚合，支持自定义分隔符（如 `/`、`、`） |
| 专辑 | 按专辑聚合 |
| 文件夹 | 按实际目录 |
| 歌单 | 用户自建列表 |
| 演出模式 | 从整个曲库或选定来源生成一份临时演出节目单，不修改原歌单 |
| 统计 | 累计播放、听过的曲目、曲库时长、常听艺术家与曲目 |

支持列表 / 表格视图与排序（各页独立记忆）。

在「设置 → 外观 → 列表与动效」可以开关平滑滚轮和堆叠滚动效果；统计页的数字更新也会使用过渡动画。

## 列表操作

右键或条目菜单常见能力：

- 加入播放队列 / 下一首播放
- 加入自建歌单
- 查看详细信息（码率、采样率、标签等）
- 从歌单移除（歌单页）

多选支持按住拖动连续选择，也可以沿已选范围拖动反选。专辑详情页可以直接顺序播放或随机播放当前歌曲；更多操作见 [交互与手势](/guide/interactions)。自建歌单可自选封面。

## 搜索

全局搜索可覆盖歌曲、艺术家、专辑，也支持用中文名称的拼音首字母搜索。歌曲、艺术家、专辑等长列表右侧有字母索引条，可以快速跳到对应位置。

## 支持的音频格式

常见可扫描格式包括：

`mp3`、`flac`、`wav`、`m4a`、`aac`、`ogg`、`opus`、`ape`、`wv`、`aiff`、`wma`、`webm`、`dsf` 等

实际播放依赖内置音频引擎与格式插件。若某格式能扫描但无法播放，优先检查文件是否损坏、是否为不支持的编码变体。

## 封面与标签

- 标签与封面由后端读取
- 封面会缓存，减少重复解码
- 大库首次建索引会更吃磁盘与时间，属正常现象

## 播放统计

「统计」页会显示累计播放次数、听过的曲目数量、艺术家 / 专辑数量和曲库总时长，并按播放次数列出常听艺术家与曲目。播放记录保存在曲库数据库中，刷新或迁移曲库时会尽量沿用已有记录。

## 数据位置与备份

| 版本 | 备份什么 |
|------|----------|
| 便携版 | 整个程序目录（里面的 `data` 最重要） |
| 安装版 | `%LOCALAPPDATA%\pure_music` 整个文件夹 |

设置、曲库、歌单、统计都在这份数据里。从曲库「移除文件夹」不会删除磁盘上的音乐文件。
