# 更新日志

从 **2.0.0** 起。每个版本默认折叠，点版本号展开。最新：**2.3.4**。

完整发布页：[GitHub](https://github.com/qingyueyin/Pure-music/releases) · [Gitee 镜像](https://gitee.com/qingyueyin/Pure-music)（同步常滞后）

<details>
<summary><strong>2.3.4</strong></summary>

**先看这些**

- 远程音乐：可连接 Navidrome、Jellyfin、WebDAV、SMB，服务器上的音乐和本地曲库一起浏览播放（#86）
- 播放输出：可选共享或独占输出设备
- 播放页更流畅：歌词、背景、进度条分开刷新，打开播放页和切歌更跟手
- 长时间播放更省资源：窗口切到后台或最小化后停掉看不见的绘制并释放缓存
- 息屏唤醒、从托盘恢复后画面卡住不动已修

**远程音乐**

- 新增：支持 Navidrome、Jellyfin、WebDAV、SMB 四种远程音乐。侧栏「远程音乐」→「添加远程源」，填地址和账号即可；远程歌曲能正常播放，显示时长和封面（#85,#86）
- 新增：远程来源的收听统计，统计页来源切到「远程」查看
- 启动时只读远程源列表，打开「远程音乐」才加载曲目；同一来源复用连接，切换更快
- 同步远程曲库时界面不再卡住
- 远程封面跳转不再自动跟随，避免账号信息被带到其它服务器
- 远程歌曲的时长写入曲库，列表里不再缺时长

**播放**

- 新增：可选共享或独占输出设备（设置 → 播放 → 输出设备）
- 连续切歌后音频占用能正常释放
- 退出时等待音量调节结束，避免声音设备被重复释放
- 同一首歌不会重复提交给系统和任务栏封面

**性能**

- 播放页的歌词、背景和进度条分开刷新，只重画变化的部分；打开播放页时不再顺带绘制曲库页
- 封面按实际显示大小解码，大封面不再整张处理
- 窗口切到后台超过 30 秒按不可见处理：停掉装饰动画、频谱和进度条，释放一部分缓存，回到前台立刻恢复
- 窗口被完全挡住时停掉整页动画；最小化期间持续释放内存
- 收紧播放中的内存上限，长时间播放不再只涨不落
- 长时间播放后占用越来越大的两个来源已修：系统媒体控制每秒新建对象、后台回声日志没关
- 切歌不再重复扫描已经缓存过的歌词；启动等首屏稳定后再显示窗口
- 流光背景降到 15fps，减少整屏模糊计算
- 图片缓存上限调整为 128 张，并随版本升级维护；缓存释放后不再被写回，避免内存回升

**曲库**

- 曲库还没对齐时不再缓存空歌单

**歌词**

- 修复：快速切歌时歌词请求没有取消，会短暂显示上一首的歌词；同一行的罗马音现在保留
- 修复：界面尺寸还没算好时歌词会滚错位置
- 修复：歌曲信息行（词曲、制作人等）和歌词行的排版路径不一致，对不齐；现在统一按逐字排版

**桌面歌词**

- 暂停后不再每秒同步进度，空闲时更省资源；拖动进度条仍会立刻对齐

**界面**

- 统计页筛选区改为自适应布局，窗口变窄不再挤在一起
- 封面取色提前，圆形封面切换更自然
- 封面搜索记住图片尺寸
- 提示关闭时取消还没完成的移除
- 设置 → 关于的贡献者列表显示加载状态，加载失败可以重试

**窗口与系统**

- 修复息屏唤醒后画面冻结
- 修复从托盘恢复后画面卡住一帧
- 窗口真正显示后才恢复绘制和动画，隐藏时只释放冷封面

**安装与更新**

- 便携版首次启动会补上开始菜单快捷方式，安装版和便携版的快捷方式分开命名
- 重复启动不再开出两个窗口
- 安装程序适配新版打包工具
- 打包时不再混入运行时数据；文件名含特殊字符时打包不会中断

**此次更新贡献者**

- @Stillrain001

<summary><strong>2.3.3</strong></summary>

**先看这些**

- 隐藏歌曲：可从曲库隐藏歌曲，文件不会删除，可随时恢复；曲库扫描现在显示阶段和进度
- 新增 AAC / ALAC 音频格式播放支持
- 播放页新增可选频谱条，进度条上方显示柱状频谱
- 播放页新增可选圆形封面，以及对应的播放效果
- 播放统计改为按日 / 周 / 月切换，可向前后翻页，报告页新增按天视图
- 最小化时停止无效画面绘制并回收可重建资源，播放和媒体控制继续

**播放**

- 新增：支持 AAC、ALAC 音频格式播放
- 新增：暂停时短暂淡出，避免声音突然停住
- 修复：手动跳转后，歌词、播放页进度条和迷你播放条时间立即跟随播放位置校正；含间奏歌曲不再残留旧位置
- 修复：播放过程中不再清理画面缓存，避免封面和歌词在播放时反复重新加载造成卡顿

**歌词**

- 修复：本地 KRC 没有配套 LRC 时，读取 KRC 自带的 `[language:]` 翻译并按时间回填
- 修复：KRC 翻译行同时支持 KRC 和标准 LRC 时间戳，一行多个时间戳也能正确对应
- 修复：从其它页面回到播放页时，逐字唱标直接对齐当前播放位置，不再从左往右慢慢追上

**界面**

- 新增：播放页频谱条，显示在进度条上方；暂停时清空残留柱（设置 → 外观 → 播放界面，默认关闭）
- 新增：主题色频谱，可让频谱条跟随播放页控件颜色
- 新增：圆形播放页封面，播放时缓慢旋转，暂停、停止或播完时减速收停；进出播放页、沉浸模式缩略图和切歌后都保留正确的旋转状态（设置 → 外观 → 播放界面，默认关闭）
- 统一页面操作按钮和图标按钮尺寸，列表、详情页和歌单等页面的操作更一致
- 切换标签页时不再重播内容入场动画

**曲库**

- 新增：隐藏歌曲。可在曲库列表中隐藏单曲或批量隐藏，文件不会被删除；隐藏后从曲库、专辑和歌手页移除，正在播放的曲目也会从播放队列移除
- 新增：隐藏歌曲管理页，可在设置 → 高级 → 隐藏歌曲中恢复单曲、批量恢复或全部恢复
- 新增：曲库扫描显示准备、扫描、保存阶段和进度百分比
- 扫描完成后显示无法读取的文件数量，扫描失败支持重试；启动扫描、首次建库和手动刷新统一显示进度
- 修复：建库失败后可直接重试，不会卡在失败状态
- 修复：正在播放的歌曲被隐藏时，暂停状态也会清空当前播放，不留下已隐藏曲目
- 修复：隐藏歌曲写入失败时给出提示并恢复列表，不会出现界面已消失但实际未隐藏的情况
- 修复：索引读取失败时仍保留隐藏状态，不会把已隐藏歌曲重新放出来

**统计**

- 收听时段改为按日、周、月切换，可向前后翻页查看其它时段，最早可翻到第一条播放记录
- 报告页新增按天视图：时段构成，以及当天首次 / 最后记录、收听跨度、最长连续活跃小时和活跃小时均播
- 统计页按窗口可用宽度重新排版，窄窗口下不再挤成一列
- 修复：统计加载失败时给出提示，点右上角刷新可重试

**窗口与系统**

- 最小化到任务栏时停止画面绘制并回收可重建资源，减少后台无效占用；恢复窗口后自动继续绘制
- 最小化期间音频播放、媒体会话和其他后台逻辑不受影响

**修复**

- 修复播放页控件在部分封面下对比不足的问题，改为从原色向黑白混合直到达到可读对比度
- 修复列表项点击或选中时背景越过圆角，搜索结果和其他列表的裁剪更一致
- DFF、DSF 等格式的流派、年份、作曲和 BPM 现在能正确读取显示

- ReplayGain 增加曲目 / 专辑两种拉齐方式：设置 → 播放
- 中间间奏增加入场：行高展开并淡入后，再按进度点亮
- 顶栏、侧栏可分别开启毛玻璃：设置 → 外观
- 便携版支持原地更新；设置 → 关于 可选择 GitHub 或 Gitee 渠道

**播放**

- 新增：歌手、文件夹、歌单详情页也可顺序播放当前列表
- 新增：ReplayGain 可选手动拉齐方式（曲目 / 专辑）；缺少当前类型标签时改用另一种
- 新增：跳过片头空白。设置 → 播放
- 新增：MIDI 可指定音色库（`.sf2` / `.sf3`）。设置 → 播放 （未测试，只新增）
- 新增：睡眠定时，支持自动延长
- 新增：记住歌曲内进度
- 写入封面或标签后，任务栏与系统媒体控件会刷新封面
- 「主题色控件」关闭时，音调与均衡器面板不再使用主题色

**歌词**

- 新增：中间间奏入场。退场按点亮反序熄灭并缩小，行高一并收起；拖离间奏时退场会播完。开头前奏仍为满高度出现
- 新增：歌词字体可独立选择。设置 → 高级；备份会包含歌词字体文件
- 新增：网络歌词获取后的写入策略「关闭」。询问 / 自动 / 关闭；已有内嵌歌词时仍会询问是否覆盖
- 新增：桌面歌词窗口图标可跟随主题色
- 上抬改为跟随当前字，折行后只抬已唱到的字
- 辉光缩放句末高亮铺满后再淡出
- 非当前行模糊按距离分档
- 切行动效按与当前行的距离错开。手动滚动后，平滑约 2 秒、弹簧约 3 秒再跟随
- 播放中回退进度会定位到目标行
- 进入播放页后，待歌词区域尺寸稳定再滚到当前行
- TTML 保留英文词间空格，相邻拉丁片段合并为词；多种翻译按偏好语言只保留一种
- 韩文注音轨与主歌词行的区分更准确
- 优化 QQ源 搜索保证正常可用

**界面**

- 新增：顶栏 / 侧栏毛玻璃。设置 → 外观
- 新增：专辑封面指针光斑。设置 → 外观 → 界面动效
- 侧栏展开时正文随侧栏平移；窗口宽度变化时切换布局
- 竖屏播放页可在封面 / 歌词 / 播放列表间切换
- 迷你播放条切歌带滑动过渡，拖动时可预览进度
- 详情页头部使用预模糊封面
- 字母索引气泡跟随滑块，分组少于三个时隐藏
- 封面取色会跳过过灰的主色
- 网格渐变色盘轮换更慢；封面律动跟随音频能量与瞬态

**曲库**

- 新增：歌曲列表可按时长、播放次数排序
- 新增：统计页常听专辑、从未播放，点击可跳转
- 歌曲详情支持显示播放次数、BPM、曲目 / 专辑音量标签
- 自然序补充：忽略装饰前缀与开头曲目序号；空标题排在最后
- 刷新时未改动的文件复用已有记录；暂时无法读取的文件从列表隐藏
- 封面按文件修改时间更新缓存
- 备份导入按完整文件写入

**演出模式**

- 新增：开演后播放列表按幕分段并显示幕名
- 新增：切幕时可显示幕名

- 新增：播放页防休眠。设置 → 高级
- 新增：更新渠道 GitHub / Gitee。（待测试，期待大伙们可反馈效果给我听哦）在：设置 → 关于

- 启动检查更新会节流

- 问题反馈会复制截断并脱敏后的日志

- 拖动进度、切行、间奏与韩文注音的跟唱错位
- 关闭播放器时的音量归一化
