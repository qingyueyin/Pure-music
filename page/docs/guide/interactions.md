# 交互与手势

一些不太显眼、但很好用的操作。

## 鼠标

| 操作 | 效果 |
|------|------|
| 侧键（后退） | 返回上一页；在沉浸模式会退出沉浸 |
| 中键 / 前进键 | 目前没有功能 |

侧键在应用里全局有效，不要求点在某个按钮上。

## 播放页

### 光标和按钮

- 鼠标停大约 **1 秒多** 不动，光标会藏起来，方便看歌词；一动就回来  
- **横屏**底下那排播放按钮：默认半隐，鼠标移到底部才完整出现  
- **竖屏**音量、EQ、桌面歌词等次要按钮：鼠标离开会淡出  
- **沉浸**（`F1`）时鼠标一动，右下角可能冒出快捷键小卡片，点问号可看完整说明  

### 歌词

| 操作 | 效果 |
|------|------|
| 点某一行 | 跳到这句开始唱的位置（可点时鼠标放上去会提示） |
| 自己滑歌词 | 大约 **2 秒**内不会强行滚回当前句，方便翻看 |
| 字号按钮 A · 左键 | 字变大 |
| 字号按钮 A · 右键 | 字变小（大约 16–48；翻译会略小一点） |
| 粗细按钮 B · 左 / 右键 | 加粗 / 变细 |
| 粗细按钮 B · 长按 | 更细地调一档 |
| 对齐 | 左 → 中 → 右循环（多声部时可能没有这个按钮） |

### 当前播放列表

切到「播放列表」视图后：

- 点某一首：切到那首（正在播的不能再点）  
- 拖右侧小条：改顺序  
- 点移除：从**当前队列**拿掉（不是删歌单、更不是删文件）  

### 更多

播放页「更多」里常见：看艺人 / 专辑、加进歌单、歌词来源（搜索或指定文件）、歌曲详细信息。

## 底部迷你条

主界面最底下那一条：

- 点封面或整条 → 进完整播放页  
- 鼠标放上去才出现播放按钮，停一会儿会再藏起来  

## 音量条

- 鼠标放在音量上，或按音量快捷键，会弹出两条滑条  
- **上面一般是本软件音量，下面是系统音量**  
- 停大约 1 秒不操作会自己收起  

## 音乐 / 艺人 / 专辑 / 歌单列表

| 操作 | 效果 |
|------|------|
| 长按一首或一张卡片 | 进入多选 |
| 多选时按住拖 | 连续多选或反选一段 |
| 右键 | 加队列、下一首、加歌单、详情、从歌单移除等（多选时右键不可用） |
| 列表滚过一屏 | 右下角出现「回到顶部」 |

## 侧栏

- **单击**「音乐 / 艺术家 / …」：换页，并记住下次启动先打开这一页（设置、统计不会当启动页）  
- **再双击当前这一页**：列表滚回顶部，相当于「刷新到刚进这页的样子」  

## 快捷键

完整表见 [快捷键](/guide/hotkeys)。在搜索框里打字时，播放用的快捷键会暂时关掉，避免空格变成暂停。

## 其它观感

- 封面会先出小图，再换成更清晰的图，减少闪一下  
- 列表往下滚时，新出现的条目会带一点滑入动画  
- 歌词跟唱细节见 [歌词](/guide/lyrics)
