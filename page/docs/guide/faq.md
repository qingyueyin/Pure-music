# 常见问题

从用户真实场景整理。

## 安装与启动

### 被 SmartScreen 拦截？

点「更多信息」→「仍要运行」。这是未签名应用的常见提示。

### 杀软报毒？

多为误报。将程序目录加入白名单。开源项目可对照 GitHub 源码与 Release。

### 安装后打不开？

1. 确认 Windows 10+
2. 确认发布包已完整解压，不是在压缩包内直接运行
3. 确认 exe 旁的 DLL、`dll/` 与 `desktop_lyric/` 都还在
4. 安装最新 Visual C++ 运行库
5. 确认程序目录可写，并查看是否被杀软隔离

### 如何更新而不丢设置？

退出旧版本，把新版本解压到新目录，再将旧目录中的 `data/` 复制过去。不要用旧版 DLL 覆盖新版本，详见 [安装指南](/guide/install#更新版本)。

### 配置丢了 / 换电脑如何迁移？

先确认是否启动了另一个目录里的程序副本；每个副本默认读取各自旁边的 `data/`。迁移电脑时拷贝整个程序目录，不要只拷 exe。

## 曲库

### 扫描很慢？

大库首次建索引要读标签和封面，属正常。后续启动会快很多。

### 有文件扫不到？

确认扩展名在支持列表内，且不在排除文件夹。必要时重新添加根目录。

### 新放进去的歌没有出现？

进入「文件夹」页点击「刷新」。程序不会持续监视磁盘变化。

### 封面或标签不对？

标签来自文件本身。可先用标签工具修正，再重新扫描 / 刷新。

## 播放与音频

### 开不了 WASAPI 独占？

- 其它程序可能占用声卡（浏览器、会议软件等）
- EQ 未归零时与独占互斥
- 失败提示 BUSY：关掉占用后重试

### 音调 / 速度无效？

这些能力主要在共享模式。切到独占后可能回退。

### 声音忽大忽小？

可开 ReplayGain（需标签含 gain），或用 EQ 预放大 / DSP 音量微调。

## 歌词

### 明明有歌词文件却不显示？

1. 与音频同目录、尽量同名
2. 扩展名优先级：`.yrc` > `.qrc` > `.krc` > `.ttml` > `.lrc`
3. 编码异常时另存 UTF-8
4. 检查是否被「本地 / 在线」策略影响

### 歌词区域是空的？

默认的本地模式不会自动联网。没有外挂或内嵌歌词时，可在「设置」→「在线歌词设置」中切换到在线来源。

### 为什么不是逐字？

逐字取决于歌词文件是否带字级时间戳。普通 LRC 通常只有行级。

### 在线歌词匹配错歌？

换源（QQ / 网易 / 酷狗 / AMLL），或修正音频的标题 / 艺人标签后重搜。需要使用本地文件时，将首选歌词来源切换为「本地」。

### 翻译 / 罗马音位置不对？

在歌词显示设置里调整注音位置：原文上 / 原文下 / 翻译下。

## 界面与系统

### 主题色不跟封面？

确认已开启封面自动取色 / Material You 相关选项，且当前曲目有封面。

### 媒体键没反应？

确认系统媒体控件（SMTC）可用，且没有其它播放器抢占会话。

### 如何反馈 Bug？

打开「设置」→「报告问题」，填写复现步骤后点击「获取日志」，再把复制的日志粘贴到 Issue 正文。内存日志退出后可能不保留，请在退出前获取。
