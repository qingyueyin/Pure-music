# 常见问题

按场景查找。功能怎么用见各指南页。

## 安装与启动

### 装安装版还是便携版？

- **安装版**：长期用这台电脑、要开始菜单 → 下载名带 `installer` 的程序  
- **便携版**：U 盘带走、绿色软件 → 下载名带 `portable` 的压缩包  

详见 [安装](/guide/install)。

### GitHub 很慢，能用 Gitee 吗？

可以。[Gitee 仓库](https://gitee.com/qingyueyin/Pure-music) 是镜像，方便国内访问。

注意：**Gitee 上的自动同步经常很慢，约等于没有**，Release / 代码可能长时间落后于 GitHub。若两边版本号或说明不一致，以 **GitHub Releases** 和本站 [更新日志](/guide/changelog) 为准；应用内检查更新也会优先 GitHub，失败时再试备用 JSON（其中含 Gitee 上的 `version.json` 路径，同样可能滞后）。

### 被 SmartScreen 拦住？

点「更多信息」→「仍要运行」。软件尚未签名时很常见。

### 杀毒软件报警？

多数是误报。把程序所在文件夹加入白名单。可对照 GitHub 源码和发布页。

### 便携版解压后打不开？

1. 系统是否为 **Windows 10 或 11**（Win7 / 8 不支持，见下一条）  
2. **完整解压**，不要在压缩包里直接双击  
3. 确认同目录有一堆 dll，以及 `dll`、`desktop_lyric` 文件夹（不要只拷一个 exe）  
4. 安装最新 Visual C++ 运行库  
5. 文件夹要能写入，并看是否被杀软隔离  

### Windows 7 / 8 能用吗？

**不能作为支持目标。** 官方只面向 Windows 10 / 11。底层用的 Flutter 桌面端也不支持 Win7/8，即使勉强拷文件过去，通常也跑不起来或不稳定。请升级系统，或换一台 Win10+ 的电脑。

### 启动很慢？

第一次或歌特别多时，要读曲库和封面，等扫描/加载走完。若一直失败见下面「曲库读不出来」。

### 为什么不能开两个窗口？

设计为单实例：再开一次会跳到已打开的窗口。若真看到两个，多半是**安装版和便携版各开了一个**（两套数据，互不相干）。

### 怎么更新又不丢设置？

- **安装版**：先退出 → 装新版覆盖；设置和曲库一般还在  
- **便携版**：解压到新文件夹 → 把旧的 `data` 文件夹拷过去（或按包里说明用升级脚本）；**不要**用旧版 dll 盖新版  

### 怎么卸载？

- **安装版**：系统「已安装的应用」里卸载；最后会问要不要删个人数据，选「否」可留着以后重装  
- **便携版**：退出后删整个文件夹；想留设置就先备份 `data`  

### 安装时「从便携版导入」失败？

- 先关掉正在跑的便携版  
- 选对文件夹（里面要有 `pure_music.exe`）  
- 如果本机已经用过安装版、数据目录里已有内容，导入步骤会跳过，避免盖掉现有数据  
- 提示导入失败时：便携版原数据不会被改，可稍后手动拷贝  

### 换电脑 / 配置好像丢了？

- **安装版**：拷贝 `%LOCALAPPDATA%\pure_music` 整个文件夹  
- **便携版**：拷贝整个程序目录（尤其 `data`）  

安装版的「程序」和「个人数据」不在同一处，备份数据不必拷安装目录。

### 安装版和便携版数据会混在一起吗？

不会。安装版用用户目录下的 `pure_music`；便携版用自己旁边的 `data`。多份便携也可以各用各的。

## 曲库与列表

### 扫描特别慢？

第一次建库要读每首歌的标签和封面，歌越多越久，属正常。以后再开会快很多。

### 有些歌扫不进来？

- 格式是否支持（见 [音乐库](/guide/library)）  
- 是否放在「排除」的文件夹里  
- 文件是否损坏或没权限  

可重新添加上层文件夹再扫一次。

### 新拷进文件夹的歌列表里没有？

到「文件夹」页点**刷新**。软件**不会**一直监视硬盘变化；**只重启软件也不会自动扫新文件**，必须点刷新（或改扫描目录后重建）。

### 磁盘上删了歌，列表里还在？

再点一次刷新（同样：只重启不够）。

### 封面、歌名、艺人对不上？

信息来自文件自己的标签。用标签工具改好后，回到本软件**刷新曲库**。点进歌曲详情可看码率等，部分信息也可在详情里改。

### 曲库读不出来 / 初始化失败？

到「设置 → 高级 → 报告问题」获取日志。常见原因：数据目录不能写、磁盘满、库文件坏了。  
可先备份整个数据文件夹，再尝试删掉其中的曲库文件后重新扫描（统计等会受影响，设置文件通常还在）。拿不准时带日志来问。

### 同一个艺人变成好几个？

「设置 → 高级 → 艺术家分隔符」：如果开了 `/` 或 `、`，标签写成「张三/李四」会拆成两人。不需要拆就删掉对应符号，再刷新。

### 搜索搜不到？

搜索靠已扫描到的歌名、艺人、专辑。标签空或写错会对不上；改标签后刷新。

### 多选不好用？

在列表里**长按**一首或一张卡片进入多选，再按住拖可选一段。多选时右键菜单不可用。

### 右键没有「下一首」？

换非多选状态再右键。也可在详情或其它菜单里找「加入队列」类选项。

### 统计页数字不对？

根据你在本软件里的播放记录统计。换过库、重建过库、或很少完整听完，数字会偏少。

### 每次打开都进设置页？

启动页由你**单击侧栏**「音乐 / 艺术家 / …」记住（设置、统计不会当启动页）。点一次你想要的那一栏即可。

### 双击侧栏当前项？

列表会回到顶部，相当于重新进这一页。

## 歌单

### 歌单和底下的「正在播放列表」有什么区别？

| | 歌单 | 当前播放列表 |
|--|------|----------------|
| 是什么 | 你保存的列表 | 这一次排队要听的顺序 |
| 在哪 | 侧栏「歌单」 | 播放页切到「播放列表」视图 |
| 关掉软件 | 还在 | 会尽量记住，但本质是「当前队列」 |

从队列里移除 ≠ 从歌单删除 ≠ 删除文件。

### 加不进歌单？

同一首不会重复加。从文件夹导入时：歌必须**已经在曲库里**；歌单名不能重复；磁盘要能写入。

### 歌单封面怎么换？

在歌单相关菜单里选封面即可。

### 从歌单里移除会删文件吗？

不会，只是不再出现在这个歌单里。

## 播放与声音

### 点了没声 / 提示播放失败？

- 文件是否被移动、改名或损坏  
- 便携版是否缺 dll（不要只拷 exe）  
- 试着关掉独占，用默认共享模式  
- 看提示是否写「请查看日志」，到高级设置里取日志  

### 开不了「独占」？

1. 别的软件是否占着声卡（浏览器、会议、其它播放器）  
2. **均衡器是否没归零**——有 EQ 时会提示冲突，先把各段和前级都拉回中间  
3. 是不是在用**蓝牙耳机 / 音箱**（见下一条）  
4. 仍失败会退回共享，可再试一次  

### 蓝牙设备能开独占吗？

**多数开不了，属正常。** 蓝牙音频在 Windows 上往往走共享通路，或不支持「独占」这类用法；即使用有线声卡能开独占，换蓝牙后也可能一点就失败或自动退回共享。

建议：蓝牙就用默认的**共享模式**听；独占更适合本机声卡、USB 有线耳放等设备。EQ、音调等也主要在共享模式下完整可用。

### 独占和 EQ 能一起开吗？

不能。要用独占，请先把 EQ 全部归零。

### 音调、变速没效果？

主要在**共享**模式下有效。开了独占后可能没了。  
若开了「保持音调」，半音变调通常会受限——先关保持音调再调半音。

### 「保持音调」是什么？

让你调速度时尽量不跑调。打开后，半音升降调往往不能同时用。

### 切歌几乎听不到淡入淡出？

只有共享模式有很短的过渡；独占是硬切。过渡本身很短，听感可能不明显。

### 有的歌特别响、有的特别轻？

- 开 **ReplayGain**（设置 → 高级；歌曲标签里要有音量信息）  
- 或用 EQ 前级、应用音量微调  
- 注意：本软件音量和系统音量是两套，快捷键只动本软件那一档  

### 快捷键调音量，系统音量为什么不动？

`Ctrl + ↑/↓` 只调**本软件**。系统总音量：点音量按钮，用下面那条滑条。

### 音量条老是自己消失？

停大约 1 秒不操作会收起，是故意的，再点或再按快捷键即可。

### ReplayGain 没感觉？

很多文件标签里没有音量信息，这时开了也不会变。可用标签工具写入后再试。

### 导入 EQ 曲线失败？

在 EQ 窗口按提示选 AutoEq 文本或文件夹。格式不对、路径无效会失败。成功后建议存成自己的预设。

### 以前存的 EQ 预设没了？

预设跟个人数据在一起。换了便携目录、清过数据、或安装版/便携版混用，会「找不到」。平时备份数据文件夹更稳。

### 随机播完队列顺序乱了？

随机会打乱当前队列；你可以再关随机、或重新从列表播放。软件会尽量记住你是否开着随机。

### 重开软件不是上次那首歌？

会尽量恢复。若文件被挪走、曲库重建过、或上次没有正常退出，可能恢复失败。

### 键盘媒体键没反应？

媒体键走系统媒体控件。关掉其它正在播的软件再试；确认 Windows 没有禁用媒体控件。

### 切歌有杂音、回声？

可到「设置 → 高级」打开回声相关日志，复现问题后写入快照，把日志发到反馈。也可先试：关独占、EQ 归零、换输出设备。

## 歌词加载

### 有歌词文件却不显示？

1. 是否和歌曲**同一文件夹**、文件名尽量相同  
2. 扩展名是否支持（`.yrc` / `.qrc` / `.krc` / `.ttml` / `.lrc` 等）  
3. 用记事本另存为 UTF-8 再试  
4. 当前是「本地」还是「在线」模式——**两边不会自动互相顶上**  

### 歌词区域一片空？

本地模式不会上网。没有外挂/内嵌时：设置 → 歌词 → 首选改成「在线」，或播放页「更多 → 歌词来源」里搜。

### 为什么不能一个字一个字亮？

看歌词是不是逐字做的。普通 LRC 常常只有「一行一个时间」。要逐字效果需 YRC、QRC、KRC、增强 LRC 或带字时间的 TTML 等。

### 本地文件和在线会不会抢？

- 本地模式：只用本地/内嵌  
- 在线模式：只用你选的源搜出来的结果  
不会自动「在线失败就改用本地」。

### 在线对上了错歌？

换源、改准歌名艺人后再搜；或在「歌词来源」里手动挑一条、指定本地文件。

### 翻译 / 注音开关是灰的？

说明**当前这首**没有翻译或注音数据。换一首或换源后再看。

- **显示 / 隐藏**开关：在**播放页**展开歌词那一排小按钮（没有数据时会是灰的）  
- **注音排在原文上还是下**：才是「设置 → 歌词 → 注音位置」——管的是排版顺序，**不是**有没有注音

### 为什么这首歌的在线歌词没有注音？

多半是**这个源本身就没提供注音**（有的歌只有原文，有的带翻译但不带注音）。不是开关坏了。可以：

- 换一个在线源再搜一次  
- 到「更多 → 歌词来源」里换一条结果试试  

都没有的话，就是这首在这些源上没有注音，软件无法凭空生成。

### 原文 / 翻译 / 注音对得不准、对不齐？

常见是**本地外挂或内嵌歌词**本身时间轴、分行、翻译对得就不好，不是显示开关的问题。可以：

1. 把首选来源改成「在线」，或播放页「更多 → 歌词来源」里搜一条更干净的  
2. 仍用本地时：换一份质量更好的歌词文件，或检查是否点错了同名但内容很差的文件  

在线也偶尔会配错歌，那时换源或手动挑一条即可。

### 简繁转换好像没变？

内容已经是目标写法，或根本不是中文时，看不出差别。

### 词曲信息、制作人那几行哪去了？

软件会收掉开头结尾常见的制作信息行，避免挡跟唱，属正常。

### 点击歌词不能跳转？

点有时间的那一行。间奏空行等可能点不了。鼠标放上去有提示时一般可点。

### 对齐按钮没了？

对唱、多声部一类歌词会按左右排布，对齐按钮可能隐藏。

## 歌词动效（缩放、发光、上抬…）

### 开了「辉光缩放」几乎看不出？

先确认四件事：

1. 「设置 → 歌词」里已经打开（**默认是关的**）  
2. 当前是**逐字**歌词，不是普通一行行的 LRC  
3. 看的是**正在唱的那一行**  
4. 字正在唱的过程中（还没唱到或唱完了，不会一直放大）  

### 为什么有的字会动、有的不会？

只有**拖得比较长**的字才会放大；更长才带一点光。快歌、字很密时，多数字达不到，看起来就像没开。拖长音、一句末尾的长音更容易看出来。

### 有放大但没有光？

正常。发光比放大「门槛」更高。同一个开关：够长才放大，再长一点才发光。

### 上抬、换行动效也不明显？

这也是**两样设置**，别混：

| | 逐字上抬 | 歌词行动效 |
|--|----------|------------|
| 管什么 | 正在唱的**字**微微抬起 | **整句**换行时怎么动（平滑 / 弹簧） |
| 什么时候有 | 逐字歌词、唱到该字时 | 切到下一句时；同一句停着不会一直弹 |
| 在哪调 | 设置 → 歌词 → 上抬方式 / 幅度 | 设置 → 歌词 → 歌词行动效 |

翻译、注音那一行字效会弱很多。辉光缩放又是第三样（长字放大/发光），和上抬、行动效无关。

### 模糊开关在哪？

在播放页，先**展开歌词那一排小按钮**，里面有模糊，不在设置列表里。

### 自己滑了歌词就不跟唱了？

大约 **2 秒**内让你自己翻看，然后会重新跟着当前句。属正常。

### 调了字号重启又变回去？

一般会记住。若清过数据、换了便携目录，会回到默认。字号大约 16–48，粗细可多档调节。

### 桌面歌词、顶部那行小字为什么没有缩放发光？

完整的逐字缩放、发光、上抬只在**主窗口播放页**。桌面歌词和顶部小行主要负责跟唱和换句动画。

### 开头没有「前奏」动画？/ 中间没有「间奏」动画？

这是**两样东西**：

| | 开头前奏 | 中间间奏 |
|--|----------|----------|
| 出现时机 | 第一句真正开唱之前，前面空了比较久 | **两句歌词之间**空了比较久 |
| 常见阈值 | 大约空 **5 秒以上**（有的路径会把开头被清掉的词曲信息时间也算进去） | 大约空 **5 秒以上** 才插入；再短一般没有圆点/动画 |
| 逐字歌词 | 空档按「上一句最后一个字唱完 → 下一句」来算，更准 | 同上 |
| 普通逐行 | 按行与行的时间算；若行时长标得满到下一句，中间间奏可能出不来或偏怪 | 换更好的歌词文件 / 在线源往往更稳 |

所以：**歌一开头就有人声、几乎没有静音**，本来就不会有前奏动画；**句与句贴得很紧**，也不会有中间间奏。不是开关坏了。

TTML 等格式若文件里自己写了空白段，也会当间奏用，规则不完全等同于 LRC 那套「满 5 秒才插」。

### 间奏动画的颜色能改吗？

能。和「有没有间奏」是两回事：

- **有没有动画**：看空档够不够长（见上一条）
- **颜色**：设置 → 外观 → **主题色间奏动画**（开了用主题色，关了用默认样式）

## 桌面歌词

### 窗口看不到？

- 播放页是否已打开桌面歌词  
- 是否被游戏全屏盖住  
- 便携版是否缺少 `desktop_lyric` 文件夹  
- 杀软是否拦了子程序  

### 和主窗口歌词对不上？

先看主窗口这首是否正常，再切一首。主程序退出后，桌面歌词一般也会关。

### 设置改了没变化？

窗口没开时改的，要**再开一次**桌面歌词才生效；开着时改一般马上能看到。可先关再开试一次。

### 颜色看不清？

开「文字描边」；或关掉「跟随主题色」，自己选已唱 / 未唱颜色。

### 主窗口有翻译，桌面没有？

**显示**和**颜色**都是两套，别混：

- 要不要显示翻译 / 注音：播放页控件 vs 「设置 → 桌面歌词」各自开关  
- 颜色：桌面歌词用「跟随主题色 / 明暗 / 自定义已唱未唱」；播放页用外观里四个「主题色 ×××」  

主窗口开了翻译，桌面还要在设置 → 桌面歌词里再开一次。

## 界面

### 主题色不跟封面？

设置 → 外观：应用主题色用「自动取色」（不要锁死成自定义色），且这首要有封面。没封面时用默认颜色。

### 只想进度条用主题色？

外观里四个开关**各自管一块**，互不替代：

| 开关 | 管什么 |
|------|--------|
| 主题色进度条 | 播放进度条要不要用主题色 |
| 主题色歌词 | 播放页歌词高亮 / 跟唱相关颜色 |
| 主题色间奏动画 | 前奏、间奏圆点等**颜色**（不管有没有间奏） |
| 主题色控件 | 播放页上一曲 / 播放 / EQ 等**按钮图标**颜色 |

只想进度条变色：只开「主题色进度条」即可。这和「应用主题色 / 封面取色」也不是一回事：后者决定整页种子色从哪来，这四个是**在种子色基础上哪些地方用它**。

### 波浪进度条没有？

外观 → 波浪进度条：竖屏 / 横屏 / 沉浸要**分别勾**。当前这种布局没勾，就是直线。

### 沉浸怎么退出？

再按 `F1`，或 `Esc`，或鼠标后退侧键。

### 播放页按钮老消失？

为了少挡歌词：底栏、次要按钮往往要**鼠标移过去**才完整显示；光标停久了也会藏。动一下鼠标就回来。

### 底部迷你条点了没进播放页？

点封面或整条；不要只点到空白边缘。

### 换了字体没变化？

选系统里真正装着的字体；换歌或重进播放页再看一眼。

### 顶部小歌词换句没动画？

设置 → 外观 → 顶部歌词切换动画。没有歌词或没显示那一行时，自然看不到。

## 快捷键与其它

### 快捷键完全没反应？

1. 是不是在搜索框里打字？（这时会暂时关掉播放快捷键）  
2. 有没有弹窗？（先 `Esc`）  
3. 其它软件是否占用了同样按键？  

键位是固定的，设置里不能改，见 [快捷键](/guide/hotkeys)。

### 检查更新失败？/ 提示的版本和 Gitee 上不一样？

- 应用会先查 **GitHub**，再试备用地址（含 Gitee 上的 `version.json`）  
- 网络到不了 GitHub 时可能失败或只能拿到较旧的备用信息  
- **Gitee 镜像不同步时**，备用源也可能是旧版——请到 GitHub Releases 或本站更新日志核对  

可到「关于」里关「启动时自动检查」，改用手动检查。

### 怎么反馈问题？

设置 → 高级 → 报告问题：写清怎么复现 → 获取日志 → 贴到 Issue。怪声、回声可先开日志录制再写快照。

## 备份

### 要备份哪些？

| 版本 | 拷贝什么 |
|------|----------|
| 便携 | 整个程序目录（至少完整的 `data`） |
| 安装 | `%LOCALAPPDATA%\pure_music` 整个文件夹 |

设置、曲库、歌单都在里面。只拷零散几个文件容易对不齐。

### U 盘上的便携版保存不了设置？

U 盘或目标文件夹必须能写入。只读盘无法写 `data`。
