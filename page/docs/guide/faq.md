# 常见问题

从用户真实场景整理。

## 安装与启动

### 被 SmartScreen 拦截？

点「更多信息」→「仍要运行」。这是未签名应用的常见提示。

### 杀软报毒？

多为误报。将程序目录加入白名单。开源项目可对照 GitHub 源码与 Release。

### 安装后打不开？

1. 确认 Windows 10+
2. 安装最新 Visual C++ 运行库
3. 确认程序目录可写（便携模式要写 `data/`）
4. 查看是否被杀软隔离

### 配置丢了 / 换电脑如何迁移？

拷贝整个程序目录（含 `data/`）。不要只拷 exe。

## 曲库

### 扫描很慢？

大库首次建索引要读标签和封面，属正常。后续启动会快很多。

### 有文件扫不到？

确认扩展名在支持列表内，且不在排除文件夹。必要时重新添加根目录。

### 封面或标签不对？

标签来自文件本身。可先用标签工具修正，再重新扫描 / 刷新。

## 播放与音频

### 开不了 WASAPI 独占？

- 其它程序可能占用声卡（浏览器、会议软件等）
- EQ 未归零时与独占互斥
- 失败提示 BUSY：关掉占用后重试

### 音调 / 速度无效？

这些能力主要在共享模式。切到独占后可能回退。

### 声音忽大忽小？

可开 ReplayGain（需标签含 gain），或用 EQ 预放大 / DSP 音量微调。

## 歌词

### 明明有歌词文件却不显示？

1. 与音频同目录、尽量同名
2. 扩展名优先级：`.yrc` > `.qrc` > `.krc` > `.ttml` > `.lrc`
3. 编码异常时另存 UTF-8
4. 检查是否被「本地 / 在线」策略影响

### 为什么不是逐字？

逐字取决于歌词文件是否带字级时间戳。普通 LRC 通常只有行级。

### 在线歌词匹配错歌？

换源（QQ / 网易 / 酷狗），或修正音频的标题 / 艺人标签后重搜。也可改「本地优先」。

### 翻译 / 罗马音位置不对？

在歌词显示设置里调整注音位置：原文上 / 原文下 / 翻译下。

## 界面与系统

### 主题色不跟封面？

确认已开启封面自动取色 / Material You 相关选项，且当前曲目有封面。

### 媒体键没反应？

确认系统媒体控件（SMTC）可用，且没有其它播放器抢占会话。

### 如何反馈 Bug？

设置中的反馈入口，或 GitHub Issue。提交时尽量附日志；注意退出后日志可能不保留，请先复制。
