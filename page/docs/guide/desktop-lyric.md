# 桌面歌词

桌面歌词以独立窗口运行，适合全屏其它应用时仍看歌词。

## 能力

| 项 | 说明 |
|----|------|
| 置顶 | 保持在其它窗口之上 |
| 字体 | 字号、字重 |
| 对齐 | 左 / 中 / 右 |
| 描边 | 提升浅色 / 复杂背景可读性 |
| 内容 | 原文、翻译、注音、歌曲信息 |
| 主题 | 可跟随播放主题色 |

## 使用建议

- 先保证播放页已正确加载歌词，再开桌面歌词
- 复杂壁纸下优先开描边
- 不需要时关闭窗口，避免额外进程占用

## 常见问题

**窗口不显示？**  
检查是否被其它全屏应用覆盖，或任务栏是否有独立歌词进程。

**内容不同步？**  
回到主程序确认当前曲目歌词是否正常；切歌后观察是否恢复。
