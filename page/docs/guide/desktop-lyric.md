# 桌面歌词

单独一个小窗口，全屏玩游戏、看视频时也能瞟歌词。在**播放页**打开；样子在「设置 → 桌面歌词」里调。

## 能调什么

| 你想… | 去哪 |
|--------|------|
| 要不要翻译、注音、歌名艺人 | 设置里三个开关 |
| 注音在原文上还是下 | 注音位置 |
| 字大小、粗细、左中右 | 文字样式 |
| 换句时怎么动 | 切换动画（上/下/左/右划、淡入淡出、吸收） |
| 花壁纸上看不清 | 打开**文字描边** |
| 颜色跟主题还是自己选 | 跟随主题色；关掉后可用明暗或自定义「已唱 / 未唱」颜色 |

跟唱节奏和主窗口一致（包括稍稍提前换句、句末收尾）。

窗口默认浮在其它窗口上面、背景透明。

::: tip
桌面歌词**没开着**时改的设置，下次打开才生效；开着时改，一般马上能看到。
:::

## 建议用法

1. 先让播放页歌词正常，再开桌面歌词  
2. 壁纸乱、字发虚 → 开描边，或关跟随主题后自己选颜色  
3. 不用时关掉，少占一个小窗口  

## 常见情况

**看不到窗口**  
是否被全屏游戏盖住；任务栏有没有歌词进程；便携版是否少拷了旁边的 `desktop_lyric` 文件夹（不要只复制一个 exe）。

**和主窗口对不上**  
先看主窗口这首歌歌词是否正常，再切一首试。主程序退出后，桌面歌词一般也会一起关。

**颜色太淡**  
开描边，或自定义已唱 / 未唱颜色。
