# 演出模式

演出模式会分析一批歌曲的声音特征，把它们排成有开场、升温、压轴和尾声的播放顺序。它只替换当前播放队列，不会改动原来的歌单或音乐文件。

## 生成一场演出

1. 在侧栏进入「演出模式」。
2. 选择整个曲库，或从文件夹、歌手、专辑和歌单中圈定素材；至少需要两首歌。
3. 点「演出设置」调整编排方向，再点「生成编排」。
4. 查看节目单和情绪曲线，满意后点「开演」。

首次使用某些歌曲时需要完整分析音频，会花一些时间；已经分析过的歌曲会走缓存，之后生成和调整会快很多。分析过程中可以停止。

## 编排设置

| 项 | 作用 |
|----|------|
| 压轴时机 | 决定整场演出大约在什么位置到达最高点 |
| 情绪起伏 | 控制前后歌曲之间的反差大小 |
| 顺滑度 | 越高越重视相邻歌曲衔接自然，越低越允许明显转折 |
| 演出规模 | 使用全部素材，或抽取 15、30、60 首 |
| 收尾风格 | 可选温暖、渐弱或燃尽 |
| 抽取口味 | 可选全部、换口味或偏向常听歌曲 |

## 查看与调整节目单

- 歌曲较多时，节目单会按开场、升温、回落、冲刺、压轴和尾声分段。
- 情绪曲线会同时显示目标走势和实际编排，点击曲线可以定位到对应歌曲。
- 在结果页展开「调节」并修改参数，节目单会使用已有分析结果重新编排。
- 最近生成的演出会保存在本机，可以再次打开；曲库中的文件发生变化时，恢复节目单可能需要重新分析。

点「开演」后会关闭随机播放，并按节目单顺序建立当前队列，歌曲之间继续使用智能衔接。
