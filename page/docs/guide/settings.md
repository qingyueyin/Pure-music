# 外观与设置

设置入口在侧栏「设置」。部分播放相关选项也会出现在播放页控件中。

## 外观

| 项 | 说明 |
|----|------|
| 主题 | 浅色 / 深色 / 跟随系统 |
| Material You | 封面取色驱动种子色；可关自动取色并自定义 |
| Monet 作用范围 | 可作用于进度条 / 歌词 / 间奏 / 控件 |
| 字体 | 使用系统已安装字体；默认含 MiSans VF |
| 背景 | 封面模糊、网格渐变、音频律动等 |

## 歌词相关

- 在线源优先级、本地优先
- 原文 / 翻译 / 罗马音显示与注音位置
- 简繁转换
- 桌面歌词样式

详见 [歌词](/guide/lyrics)、[桌面歌词](/guide/desktop-lyric)。

## 播放 / 高级

- 输出模式（共享 / WASAPI 独占）
- EQ、音调、速度
- 艺术家分隔符
- 更新检查、日志与反馈入口

## 数据与备份

便携模式数据在程序旁 `data/`：

- 设置 JSON
- 曲库 SQLite
- 缓存

迁移电脑时，拷贝整个程序目录最省事。
