# 设置

侧栏进入「设置」。EQ、音调在播放页调节。

## 外观

| 项 | 说明 |
|----|------|
| 明暗模式 | 浅色、深色，或跟随系统 |
| 配色方式 | MD3 从主题色生成配色；独立模式则直接使用主题色 |
| 主题色来源 | 跟随封面，或使用固定颜色 |
| 应用背景 | 选择图片，并调节强度与模糊 |
| 界面动效 | 堆叠滚动、页面切换、卡片交互、详情头部收拢、统计数字过渡，可分别开关。关闭页面切换的层级推入后仍保留较短过渡；系统要求减少动效时优先服从系统 |
| 播放页背景 | 封面取色渐变，或封面律动。律动背景可跟随音频起伏 |
| 主题色进度条 | 进度条是否使用主题色 |
| 主题色歌词 | 歌词高亮是否使用主题色 |
| 主题色间奏 | 前奏、间奏圆点的颜色，不决定是否出现间奏 |
| 主题色控件 | 播放页按钮是否使用主题色 |
| 播放控件常驻 | 开启后底部控件保持显示；关闭后鼠标移入底部时显示 |
| 波浪进度条 | 竖屏、横屏、横屏沉浸分别勾选；未勾选则为直线 |
| 顶部歌词切换动画 | 上划、下划、左划、右划、淡入淡出、吸收 |

字体在「高级」。

## 歌词

| 项 | 说明 |
|----|------|
| 首选歌词来源 | 外置 / 内嵌（不联网）或在线 |
| 默认在线源 | QQ / 酷狗 / 网易 / AMLL |
| 保留歌曲信息 | 是否在歌词中显示词曲作者等信息 |
| 歌词转换 | 不转换 / 繁转简 / 简转繁 |
| 歌词写入 | 标准 / 逐字 / 增强 LRC；可包含翻译、罗马音，写入标签或保存为外部 LRC |
| 辉光缩放 | 默认关闭。需要逐字歌词，较长的字才会放大，更长才带辉光。见 [FAQ](/guide/faq#开了辉光缩放为什么几乎看不出) |
| 注音位置 | 排版顺序：上 / 下 / 翻译下。不决定是否有注音数据 |
| 歌词行动效 | 整句换行时：平滑或弹簧。与逐字上抬不同 |
| 逐字上抬 | 正在演唱的字微微抬起 |

播放页展开歌词条，还可调节字号、粗细、对齐、模糊和各轨显示。见 [歌词](/guide/lyrics)。

## 播放

| 项 | 说明 |
|----|------|
| ReplayGain | 带音量标签的曲目自动拉齐音量 |
| 切歌过渡 | 无缝、淡入淡出、交叉淡化、智能衔接 |
| 任务栏播放控制 | 缩略图中的上一首、播放、下一首 |
| Alt+Tab 封面预览 | 使用当前封面作为窗口预览 |
| 封面预览大小 | 封面在预览中的占比；放大可能降低清晰度 |
| 应用内快捷键 | 仅在窗口前台生效 |
| 全局热键 | 最小化后仍可使用，需带 Ctrl / Alt / Shift |

EQ、独占、音调在播放页调节，见 [播放与音频](/guide/playback)。

## 桌面歌词

窗口未启动时修改的选项，将在下次打开时生效；已启动时一般立即生效。

| 项 | 说明 |
|----|------|
| 翻译 / 注音 / 歌曲信息 | 是否显示 |
| 注音位置 | 相对原文、翻译的位置 |
| 对齐 | 左 / 中 / 右；双行时可交错 |
| 切换动画 | 与顶部歌词类似的六种 |
| 字号 / 翻译字号 / 粗细 | 主字号约 14–48；增大主字号时翻译默认略小，也可单独调节 |
| 文字描边 | 背景复杂、文字不够清晰时开启 |
| 跟随主题色 | 开启后跟随播放页主题；关闭后可手动配色 |
| 明暗配色 | 不跟随主题时：跟随 / 浅色 / 深色 |
| 已播放 / 未播放颜色 | 自定义已唱与未唱颜色 |

详见 [桌面歌词](/guide/desktop-lyric)。

## 高级

| 项 | 说明 |
|----|------|
| 关闭主窗口时 | 退出程序，或最小化到通知区并继续播放 |
| 艺术家分隔符 | 例如 `/`、`、`：标签写成「A/B」时拆成两名艺人 |
| 界面字体 | 选择系统已安装的字体 |
| 回声排查日志 | 出现异常回声时：开始录制 → 复现 → 写入快照，将日志用于反馈 |

## 关于

| 项 | 说明 |
|----|------|
| 当前版本 | 当前安装的版本 |
| 检查更新 | 手动检查新版本 |
| 启动时自动检查更新 | 启动后稍后自动检查 |
| 官网 / 仓库 / 报告问题 | 外部链接 |
| 贡献者 | 联网读取项目贡献者 |

## 数据位置

| 版本 | 备份内容 |
|------|----------|
| 便携版 | 整个程序文件夹，其中 `data/` 最为重要 |
| 安装版 | `%LOCALAPPDATA%\pure_music` 整个文件夹 |

其中包含设置、曲库和歌单。更换电脑时复制该目录即可。安装步骤见 [安装](/guide/install)。
