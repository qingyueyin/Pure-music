# 外观与设置

侧栏点「设置」。播放、EQ、音调等也会出现在播放页按钮上。

设置按主题、背景、播放界面、歌词内容、歌词写入、桌面歌词窗口等分组进入，常用项不必在一个长页面里反复查找。

## 外观

| 项 | 怎么用 |
|----|--------|
| 主题 | 浅色 / 深色 / 跟系统 |
| 应用主题色 | 整页种子色：跟着封面自动变，或关掉后自己选固定色 |
| 主题色进度条 | 进度条用不用上面的主题色 |
| 主题色歌词 | 播放页歌词跟唱相关颜色 |
| 主题色间奏动画 | 前奏/间奏圆点等颜色（**不决定**有没有间奏） |
| 主题色控件 | 播放页按钮图标颜色 |
| 播放控件常驻 | 打开后播放页底部控件一直显示；关闭后鼠标移入底部才显示 |
| 波浪进度条 | 竖屏、横屏、沉浸**分开勾**；没勾的布局就是普通直线进度条 |
| 顶部歌词切换动画 | 上一句换成下一句时的动效：上/下/左/右划、淡入淡出、吸收 |
| 自定义字体 | 选电脑里已安装的字体 |

播放页背景会跟封面取色一起变。

「界面动效」里可以分别控制堆叠滚动、页面切换、卡片交互、详情页头部收拢和数据更新过渡。关闭页面切换的层级推入后会保留较短的基础过渡；系统要求减少动态效果时会优先服从系统设置。

## 歌词

| 项 | 怎么用 |
|----|--------|
| 首选歌词来源 | 本地（不联网）或在线 |
| 默认在线源 | QQ / 酷狗 / 网易 / AMLL |
| 歌词转换 | 不转 / 繁转简 / 简转繁 |
| 歌词写入 | 选择标准 / 逐字 / 增强 LRC，控制翻译、罗马音、标签写入和外部 LRC 保存 |
| 辉光缩放效果 | 默认关。打开后：要有**逐字**歌词，且拖得比较长的字才会缩放，更长才带光。详见 [FAQ](/guide/faq#开了辉光缩放为什么几乎看不出) |
| 注音位置 | 只调**排版顺序**（上/下/翻译下），不管有没有注音数据 |
| 歌词行动效 | 整句**换行**时：平滑或弹簧（不是逐字上抬） |
| 逐字上抬 | 正在唱的**字**微抬；与行动效、辉光缩放是三样不同的东西 |

播放页展开歌词条，还能调字号、粗细、对齐、模糊、各轨显示。更多说明见 [歌词](/guide/lyrics)。

## 桌面歌词

单独一页。窗口**还没开**时改的选项，会在下次打开桌面歌词时生效；已经开着时一般马上能看到。

| 项 | 怎么用 |
|----|--------|
| 翻译 / 注音 / 歌曲信息 | 要不要显示 |
| 注音位置 | 相对原文、翻译的位置 |
| 对齐 | 左 / 中 / 右 |
| 切换动画 | 与顶部小歌词类似的六种 |
| 字号 / 翻译字号 / 粗细 | 主字号大约 14–48；调大主字号时，翻译默认会略小一号，也可单独拖 |
| 文字描边 | 壁纸花、字看不清时打开 |
| 跟随主题色 | 开：跟播放页主题；关：可选手动配色 |
| 明暗配色 | 不跟主题时：跟随 / 浅色 / 深色 |
| 已播放 / 未播放颜色 | 自己选颜色和深浅 |

详见 [桌面歌词](/guide/desktop-lyric)。

## 高级

| 项 | 怎么用 |
|----|--------|
| ReplayGain | 有音量标签的歌自动拉齐一点 |
| 艺术家分隔符 | 例如 `/`、`、`：标签写成「A/B」时拆成两个艺人 |
| 自定义字体 | 同外观，选系统字体 |
| 回声排查日志 | 遇到怪回声时：开始录 → 复现 → 写快照，把日志发给反馈 |
| 创建问题 / 报告 | 写清步骤，点「获取日志」再去提 Issue |

## 播放控制

| 项 | 怎么用 |
|----|--------|
| 任务栏播放控制 | 在任务栏缩略图中显示播放、暂停和上下曲按钮 |
| Alt+Tab 封面预览 | 用当前歌曲封面作为窗口预览，可单独关闭 |
| 封面预览大小 | 调节封面在窗口预览中的占比；放大后可能没那么清晰 |

EQ、独占、音调在**播放页**调，见 [播放与音频](/guide/playback)。

## 关于

| 项 | 怎么用 |
|----|--------|
| 当前版本 | 看自己装的是哪一版 |
| 检查更新 | 手动查有没有新版 |
| 启动时自动检查更新 | 打开软件后过一会儿自动查（可关） |
| 官网 / 仓库 / Issue | 外链 |
| 贡献者 | 联网读取项目贡献者并打开对应主页 |

## 数据在哪、怎么备份

| 你用的版本 | 备份什么 |
|------------|----------|
| 便携版 | 整个程序文件夹（里面的 `data/` 最重要） |
| 安装版 | `%LOCALAPPDATA%\pure_music` 整个文件夹 |

里面是设置、曲库、歌单等。换电脑就拷这一份。安装步骤见 [安装](/guide/install)。
