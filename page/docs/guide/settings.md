# 设置

按页签找。具体怎么用见各功能页。

## 外观

明暗、主题色来源（封面 / 系统 / 自定义）、窗口背景、播放页配色、波浪进度条、频谱条、主题色频谱。

## 歌词

首选来源、写入策略、翻译 / 注音、逐字动效。见 [歌词](/guide/lyrics)。

## 播放

切歌过渡、ReplayGain、片头空白、输出设备、任务栏按钮、应用内快捷键和全局热键。见 [播放与音频](/guide/playback)、[操作指南](/guide/interactions)。

## 桌面歌词

对齐、颜色、竖排 / 双行、置顶。见 [桌面歌词](/guide/desktop-lyric)。

## 高级

字体、备份、关闭窗口时退出或进通知区、播放页防休眠。

## 关于

版本、检查更新、报告问题。
