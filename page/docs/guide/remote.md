# 远程音乐
音乐放在 NAS 或服务器上时，不用先拷到本机。
## 添加远程源
侧栏「远程音乐」→「添加远程源」，选类型后填地址和账号。
**Navidrome** — 兼容 Subsonic API 的服务器，同步后可浏览全部歌曲。
**Jellyfin** — 填 API 密钥时，用户名一栏留空。
**WebDAV** — 按目录列表读取音频文件，封面和时长可能拿不到。
**SMB** — 填 `\\服务器\共享名` 或已挂载的盘符；账号密码留空时用 Windows 已保存的凭据。
名称可以留空，会自动起名。
## 同步与浏览
添加后点源上的「同步」，只读取服务器上的音乐信息，不改文件。
启动时只加载源列表，打开「远程音乐」才去拉曲目。
点进某个源可看该源的全部歌曲，播放、进度和歌词按本地歌曲一样处理。
## 收听统计
远程播放单独记录，到「统计」页把来源切到「远程」查看。
## 常见问题
**同步后没有歌曲** — 确认服务器上的音乐目录，或点「同步」重试。
**封面或时长缺失** — WebDAV 只按目录列表读取，可能拿不到这两项。
**播放失败** — 检查地址协议是否正确，以及账号是否有该目录的读取权限。
