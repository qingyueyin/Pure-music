# 快速上手

从导入曲库到开始播放，大约几分钟。

## 导入音乐

<div class="pm-steps">
  <div class="pm-step">
    <div class="pm-step-num">1</div>
    <div class="pm-step-body">
      <h3>添加文件夹</h3>
      <p>首次启动走欢迎页；之后可在「文件夹」管理中继续添加或排除目录。</p>

  </div>

## 侧栏导航

| 入口 | 用途 |
|------|------|
| 音乐 | 全部歌曲列表 |
| 艺术家 / 专辑 | 按元数据分组 |
| 文件夹 | 按目录结构浏览 |
| 歌单 | 自建列表 |
| 统计 | 最常播放等 |
| 设置 | 外观、歌词、高级项 |

## 播放页基础

- 竖屏 / 横屏会自动适配；`F1` 进入沉浸模式
- 可切换「仅主区 / 带歌词 / 带播放列表」
- 封面会取色并驱动主题与背景
- 更多见 [播放与音频](/guide/playback)、[歌词](/guide/lyrics)
