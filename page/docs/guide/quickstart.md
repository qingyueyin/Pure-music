# 快速上手

从导入曲库到开始播放，大约几分钟。

::: info 音乐不会被搬走
程序直接读取你选择的文件夹，只在 `data/` 中保存索引和设置，不会复制、移动或删除原音乐文件。
:::

## 侧栏导航

| 入口 | 用途 |
|------|------|
| 音乐 | 全部歌曲列表 |
| 艺术家 / 专辑 | 按元数据分组 |
| 文件夹 | 按目录结构浏览 |
| 歌单 | 自建列表 |
| 统计 | 最常播放等 |
| 设置 | 外观、歌词、高级项 |

## 播放页基础

- 竖屏 / 横屏会自动适配；`F1` 进入沉浸模式
- 可切换「仅主区 / 带歌词 / 带播放列表」
- 封面会取色并驱动主题与背景
- 更多见 [播放与音频](/guide/playback)、[歌词](/guide/lyrics)

::: tip 第一次播放没有歌词？
默认使用本地歌词模式，只读取外挂或内嵌歌词。需要联网搜索时，到「设置」→「在线歌词设置」把首选来源切换为「在线」。
:::

## 以后新增音乐

- 新文件放进已添加的目录后，进入「文件夹」并点击「刷新」
- 要增减扫描目录，进入「文件夹」→「文件夹管理」
- 从曲库移除文件夹只会取消索引，不会删除磁盘上的音乐
